# Activation Contract
Use for animated explainers, product stories, title sequences, social clips, or translating a visual brief into a video.

# Hard Rules
- Read visual references for composition, pacing, palette, typography, and movement; create an original result.
- Follow the current project's structure and tools. Choose Remotion when it is already part of the project or specifically requested.
- Distinguish concept, preview, and finished render. Inspect output before calling it complete.
- Keep changes focused and retain source assets.

# Decision Gates
Ask only for missing choices that change the result: audience, message, platform, duration, frame shape, brand materials, or call to action. If enough is known, proceed and state assumptions.

# Execution Steps
1. Define the audience, message, visual direction, palette, type, pacing, and delivery format.
2. Plan a timed sequence with an opening hook, story beats, transitions, captions, audio cues, and ending. Check the combined timing against the target duration.
3. Build scenes using the project's established approach. Make text legible on mobile, movement purposeful, and key content fit within safe margins.
4. Start with the requested frame shape. Typical formats are 16:9, 9:16, 1:1, and 4:5; verify platform-specific requirements when needed.
5. Preview the full result. Check timing, cuts, typography, branding, audio sync, frame edges, and ending; refine visible issues.

# Output Contract
Report the creative direction, storyboard, changed or generated file locations, verified format and duration, preview checks, assumptions, and unresolved limitations. Do not present a storyboard as a rendered video.
